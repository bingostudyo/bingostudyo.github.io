BINGO STÜDYO - KURULUM
1. GitHub'da bingostudyo.github.io adlı PUBLIC repository oluşturun.
2. ZIP içindeki DOSYALARI (üst klasörü değil) repository ana dizinine yükleyin ve Commit changes seçin.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Yayınlandıktan sonra https://bingostudyo.github.io/ ve https://bingostudyo.github.io/app-ads.txt adreslerini kontrol edin.
5. Gizlilik Politikası ve Kullanım Koşulları şu an açıkça TASLAK: gerçek uygulama veri pratiklerine göre tamamlamadan Play Console'a nihai politika olarak bağlamayın.
6. AdMob doğrulaması için Play Console geliştirici web sitesi alanına doğru site adresini ekleyin; AdMob'da doğrulamayı kontrol edin. GitHub Pages alan adının AdMob tarafından kabul edildiğini ayrıca doğrulayın; gerekirse özel alan adı kullanın.
7. Mağaza bağlantısı açılınca ana sayfaya ekleyin.
